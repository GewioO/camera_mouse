## Модуль 2 — Культя

### Рівні ампутації (обидва потрібно підтримати)

**2A — Ампутація нижче ліктя** (немає кисті, є передпліччя)

Доступні рухи:
- Пронація / супінація (обертання передпліччя)
- Згинання / розгинання ліктя
- Відведення ліктем вліво / вправо

Маппінг жестів:
| Рух | Дія |
|-----|-----|
| Рух передпліччям | Курсор |
| Пронація (вниз) | Лівий клік |
| Супінація (вгору) | Правий клік |
| Швидке згинання ліктя | Скролінг вгору |
| Швидке розгинання | Скролінг вниз |
| Утримання 1с | Drag mode |

Технічно:
- Landmark кінця культі = `RIGHT_WRIST` (15/16)
- Опорна точка = `RIGHT_ELBOW` (13/14)
- Пронація через `z`-координату: `wrist.z - elbow.z`
- Кут нахилу через `arctan2`

**2B — Ампутація вище ліктя** (немає передпліччя)

Доступні рухи:
- Підйом / опускання плеча
- Відведення плеча вбік
- Внутрішня / зовнішня ротація
- Флексія / екстензія вперед-назад

Маппінг жестів:
| Рух | Дія |
|-----|-----|
| Рух плечем | Курсор |
| Підйом плеча (шраг) | Лівий клік |
| Відведення вперед | Правий клік |
| Внутрішня ротація | Скролінг вгору |
| Зовнішня ротація | Скролінг вниз |

Технічно:
- Landmark кінця культі = `RIGHT_ELBOW` (13/14)
- Опорна точка = `RIGHT_SHOULDER` (11/12)

### Спільна архітектура модуля культі

```
MediaPipe Pose
     ↓
landmarks (плече → лікоть → зап'ястя)
     ↓
вектор ознак (кути, швидкість, z-зміщення)
     ↓
класифікатор жестів (sklearn або keras)
     ↓
дія миші
```

### Модель детекції
- **Базова:** MediaPipe Pose (`mp.solutions.pose`)
- **Альтернатива:** YOLOv8 Pose з fine-tuning на своїх даних
- **Класифікатор:** RandomForestClassifier або маленька нейромережа

### Тестування
- Запустити MediaPipe Pose на відео з рухами культі
- Візуалізувати landmarks на кадрах — перевірити чи детектується культя
- Перевірити впевненість (`visibility`) кожного landmark

## Модуль 3 — Очі

### Можливі дії
| Жест | Дія |
|------|-----|
| Напрямок погляду | Рух курсора |
| Моргання лівим оком | Лівий клік |
| Моргання правим оком | Правий клік |
| Довге заплющення | Drag mode |
| Подвійне моргання | Подвійний клік |

### Комбінація з культею
Очі як **тригер** (клік), культя як **курсор** — ергономічне поєднання.

### Модель
- **MediaPipe Face Mesh** з `refine_landmarks=True` (вмикає Iris модель)
- Зіниця лівого ока: landmark `468`
- Зіниця правого ока: landmark `473`
- Напрямок погляду: відносне положення зіниці всередині контуру ока

### Головна складність
**Калібрування** — потрібен крок при старті:
- Користувач дивиться у 4 кути екрану
- Модель запам'ятовує діапазони координат зіниці

### Відкриті питання модуля очей
